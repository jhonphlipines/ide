Quick Start Guide

Executing code via Judge0 API is straightforward. Follow these three steps to get your first submission running.

1. Get an API Key

Sign up on Sulu to get your API key. We offer a generous free tier for developers.

2. Submit Code

Send a POST request to /submissions with your source code, language ID, and optional input.

3. Get Result

The API will return a unique token. Use it to poll the /submissions/:token endpoint for the execution result.

Simple Integration

Judge0 works with any programming language that can make HTTP requests. Here is a simple example using cURL and Python.

cURL Python JavaScript (Node.js)
curl -X POST 'https://ce.judge0.com/submissions?base64_encoded=true&wait=false' \ -H 'Content-Type: application/json' \ -H 'Authorization: Bearer YOUR_API_KEY' \ -d '{ "source_code": "I2luY2x1ZGUgPGlvc3RyZWFtPgoKaW50IG1haW4oKSB7CiAgICBzdGQ6OmNvdXQgPDwgIkhlbGxvLCBKdWRnZTAhIiA8PCBzdGQ6OmVuZGw7CiAgICByZXR1cm4gMDsKfQ==", "language_id": 54 }'
import requests url = "https://ce.judge0.com/submissions" payload = { "source_code": "print('Hello, Judge0!')", "language_id": 71, } headers = { "Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json" } response = requests.post(url, json=payload, headers=headers) print(response.json())
const axios = require('axios'); async function runCode() { const response = await axios.post('https://ce.judge0.com/submissions', { source_code: "console.log('Hello, Judge0!')", language_id: 63 }, { headers: { 'Authorization': 'Bearer YOUR_API_KEY', 'Content-Type': 'application/json' } }); console.log(response.data); } runCode();
